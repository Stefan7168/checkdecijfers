# Chart frame styling + floating Style panel Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** A "Frame" tab in the chart's Style panel (background colour/gradient/own image, padding, corners, shadow, inset, aspect ratio) that shows on screen AND in the PNG/SVG download, and the Style panel itself becomes a floating panel beside the chart. Spec: `docs/superpowers/specs/2026-09-09-story-mode-and-embed-design.md` Part C (owner decisions C0–C4).

**Architecture:** The frame is six new keys on `ChartPresentation` (pure model in `web/lib/chart-presentation.ts`, allow-listed by the sanitizer, saved with the account default except the image). A `ChartFrame` wrapper draws it on screen around the chart's export container; `attributedSvgMarkup` wraps the exported chart svg in an outer svg that bakes the same frame. The uploaded image is a browser-held data URL in `ChartView` state, never in the presentation object or the database. `ChartConfigPanel` gains the Frame tab and moves into a portal-positioned floating `role="dialog"`; its open state stays in `ChartView` (`openPanel`), with a tiny context so only one chart's panel is open per page.

**Tech Stack:** Next.js 15 / React 19, Recharts, zod, shadcn `Button`, vitest + Testing Library (jsdom), the message catalogue.

## Global Constraints
- **Honesty (docs/05):** the frame carries no text and touches no number/marker; every whole-card digit scan in `chart.test.tsx` must keep passing with a frame on (add one framed case per language). The attribution line is baked INSIDE the frame in every export (R4).
- **No server, no schema, no spend:** the image never leaves the browser; `{ kind: 'image' }` in the presentation is only a flag; saving a default drops it to `'none'` and says so. Migration 028 unchanged (the counter's event regex `^[a-z_]{1,40}$` admits `frame_changed`).
- **Every new interface string** has an `nl` and an `en` entry; no digits in message values (name sizes in words: none/small/medium/large; ratios are labelled "Widescreen", "Portrait", "Square", "Social", "As is" — the ratio numbers appear in NO text node; use them only in `value` attributes / code).
- **House ARIA**: hand-rolled dialog, `aria-labelledby`, Escape + Close button close and refocus the trigger; a click outside does not close; focus moves into the panel on open; no focus trap (non-modal).
- **What you see is what you download:** on-screen CSS values and exported SVG values come from ONE px map per key (`FRAME_PADDING_PX`, `FRAME_CORNER_PX`, `FRAME_INSET_PX`, `FRAME_SHADOW`), never two literals.
- The Story panel keeps its slot under the chart; the one-open-panel rule between Style and Story stays (`openPanel`).
- Commands: web tests `cd web && npx vitest run <files>`; typecheck `npx tsc --noEmit -p web` (root); build `cd web && npx next build`. Commit trailer `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.

### Task 1: The frame in the presentation model (pure)
**Files:** `web/lib/chart-presentation.ts`, `web/lib/chart-presentation.test.ts`

**Interfaces (produce exactly these):**
```ts
export type FramePadding = 'none' | 'small' | 'medium' | 'large';
export type FrameCorners = 'square' | 'rounded' | 'veryRounded';
export type FrameShadow = 'none' | 'soft' | 'strong';
export type FrameInset = 'none' | 'small' | 'large';
export type FrameAspect = 'auto' | '16:9' | '4:5' | '1:1' | '1.91:1';
export type FrameBackground =
  | 'none'
  | { kind: 'solid'; hex: string }
  | { kind: 'gradient'; from: string; to: string }
  | { kind: 'image' };
// ChartPresentation gains: frameBackground, framePadding, frameCorners, frameShadow, frameInset, frameAspect
export const FRAME_PADDING_PX: Record<FramePadding, number> = { none: 0, small: 16, medium: 32, large: 56 };
export const FRAME_CORNER_PX: Record<FrameCorners, number> = { square: 0, rounded: 12, veryRounded: 28 };
export const FRAME_INSET_PX: Record<FrameInset, number> = { none: 0, small: 12, large: 24 };
/** One shadow definition used by CSS (box-shadow) and SVG (feDropShadow) alike. */
export const FRAME_SHADOW: Record<FrameShadow, { dx: number; dy: number; blur: number; alpha: number } | null> = { none: null, soft: { dx: 0, dy: 4, blur: 12, alpha: 0.18 }, strong: { dx: 0, dy: 10, blur: 28, alpha: 0.32 } };
export const FRAME_GRADIENT_ANGLE = 135;
export const FRAME_GRADIENT_PRESETS: readonly { id: 'dawn' | 'ocean' | 'forest' | 'berry' | 'slate' | 'sand'; from: string; to: string }[];
export function frameAspectRatio(aspect: FrameAspect): number | null; // '16:9' → 16/9 …, 'auto' → null
/** The colours the series must stay legible against: the inset card colour when inset is on (card light/dark), else the solid hex or both gradient ends; 'none'/'image' → the card colours (today's behaviour). */
export function frameBackdrops(values: Pick<ChartPresentation, 'frameBackground' | 'frameInset'>): string[];
export type FrameValues = Pick<ChartPresentation, 'frameBackground' | 'framePadding' | 'frameCorners' | 'frameShadow' | 'frameInset' | 'frameAspect'>;
export function isFramePristine(values: FrameValues): boolean;
```

### Task 4: The frame in the export
**Files:** `web/components/chart-download.tsx`, `web/components/chart-download.test.tsx`, `web/components/chart.tsx`

**Interface:** `attributedSvgMarkup(svg, attributionText, resolvePaint = defaultResolvePaint, frame?: { values: FrameValues; image: string | null })` — when `frame` is absent or pristine-with-no-image the output is byte-identical to today (pin by test). Otherwise build an OUTER `<svg xmlns width height viewBox>`: outer size = chart width + 2·padding + 2·inset (+ shadow margin = blur + |dy| on each side when shadow ≠ none), outer height = chart total height (incl. the attribution footer) + the same; with an aspect ratio, the outer box is widened/heightened to the ratio (never cropped: the larger of the two dimensions is extended and the content centred). Children in order: `<defs>` with `<linearGradient id="frame-bg" gradientTransform="rotate(135)">` when gradient and `<filter id="frame-shadow"><feDropShadow dx dy stdDeviation flood-opacity/></filter>` when shadow; the background: `<rect rx fill>` (solid / `url(#frame-bg)`) or `<image href={dataUrl} width height preserveAspectRatio="xMidYMid slice" clip-path>` with a `<clipPath>` for the corners; with a shadow, the background rect gets `filter="url(#frame-shadow)"`; the inset card `<rect fill="#ffffff" rx>` (light card colour in exports — exports are white-background today); then the chart svg NESTED (`<svg x y width height viewBox>` with the existing attributed content — the existing white `bg` rect and footer text stay inside the nested svg, so the attribution is inside the frame). `downloadPng` measures the OUTER size (parse width/height from the produced markup or return them from a new `framedSvgMarkup` helper) and fills the canvas with the frame's solid colour when solid, else transparent → white only when the frame is none (today's fill).
